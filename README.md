# 👟 Shouse Store - Sneakers E-Commerce Landing Page

## 📖 Overview

**Shouse Store** is a modern and responsive sneaker e-commerce landing page built using **HTML, CSS, and JavaScript**. The website showcases stylish sneakers with an attractive user interface, category filtering, featured products, search functionality, and a fully responsive design for desktop and mobile devices.

The goal of this project is to provide a clean and visually appealing online shopping experience for sneaker enthusiasts.

---

## ✨ Features

* 🏠 Modern Hero Section
* 👟 Featured Sneaker Collection
* 📂 Shop by Categories
* 🔍 Search Bar Interface
* 🛒 Shopping Cart Icon
* 👤 User Account Icon
* 📱 Responsive Mobile Navigation
* 🎨 Modern UI/UX Design

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/shouse-store.git
```

### 2. Open the Project

Navigate to the project folder:

```bash
cd shouse-store
```

### 3. Run the Website

Simply open:

```text
index.html
```

in your browser.

You can also use the VS Code Live Server extension for a better development experience.
